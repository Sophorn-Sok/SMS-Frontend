# SMS Frontend

Frontend application for the **School Management System (SMS)** — a web platform covering the full academic lifecycle from student enrollment to graduation, across seven role-based portals: Student Affairs, Academic Affairs, Teacher, Controller of Examination, Student, Principal, and Admin.

## Roles Covered

| Role | Portal Focus |
|---|---|
| Student Affairs | Student record creation, bulk upload, enrollment reporting |
| Academic Affairs | Programs, majors, semesters, course registration, timetables |
| Teacher | Attendance, assignments, grading, exam papers |
| Controller of Examination | Exam scheduling, grade approval, results, transcripts, graduation |
| Student | Self-service portal (timetable, attendance, grades, exams, transcript requests) |
| Principal | Institutional analytics and reporting dashboards |
| Admin | Account management, audit log |
